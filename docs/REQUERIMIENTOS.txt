REQUERIMIENTOS FUNCIONALES ID HUB Plataforma integral de gestión para WISP y comunidades Versión: 1.0 Fecha: 30 de septiembre de 2026 Modalidad: Plataforma Web + App Técnico/Cobrador + App Cliente Modelo: SaaS Multiempresa / Multi-WISP
1. OBJETIVO GENERAL ID-Hub será una plataforma de gestión especializada para proveedores de Internet inalámbrico (WISP) que permita administrar de manera centralizada:
• Clientes. • Planes y servicios. • Cobranza. • Pagos. • Cortes y reconexiones. • Antenas y CPE. • Repetidores y torres. • Equipamiento MikroTik. • Tickets de soporte. • Técnicos y cobradores. • Rutas de trabajo. • Evidencias fotográﬁcas. • Geolocalización. • Portal cautivo. • Promociones. • Referidos. • Indicadores ﬁnancieros. • Crecimiento y cobertura. • Aplicación móvil del cliente. El sistema deberá sustituir procesos realizados actualmente mediante cuadernos, hojas de cálculo, mensajes de WhatsApp y controles manuales.
2. ARQUITECTURA GENERAL La plataforma estará compuesta por: A. Panel administrativo web Para propietarios, administradores, cobranza, soporte y supervisores. B. Motor de integración de red Comunicación con equipos MikroTik y demás infraestructura compatible. C. Aplicación móvil de técnicos/cobradores Para ejecución y seguimiento de actividades en campo. D. Aplicación móvil del cliente Para consulta, pago, soporte y administración de su servicio.

E. Portal cautivo Para autenticación de usuarios y promoción/publicidad. F. Motor de automatizaciones Encargado de cortes, reconexiones, notiﬁcaciones, cobranza y alertas. G. Sistema GIS / mapa operativo Visualización geográﬁca de infraestructura, clientes, técnicos, incidencias y cobertura.

54. DIFERENCIADOR FUNCIONAL DE ID-Hub El concepto central del producto no debe ser únicamente "software para administrar clientes WISP". Debe plantearse como: ID-Hub integra en una sola plataforma la cobranza, la red, el mapa y las operaciones de campo. La ventaja funcional está en conectar:


DINERO → Cobranza y pagos RED → MikroTik, antenas y repetidores CAMPO → Técnicos, rutas y evidencias CLIENTE → App, WhatsApp y soporte CRECIMIENTO → BI, demanda y expansión Todo alimentado por una misma base de datos operativa. 55.
